# Backend Validation Practice

A backend practice project focused on learning and comparing different validation approaches in Node.js and Express.

This project covers validation using:

- Express Validator
- Joi
- Zod

## Tech Stack

- Node.js
- Express.js
- MySQL
- express-validator
- Joi
- Zod
- Nodemon

## What I Learned

- How to validate request body data
- How to check email format
- How to validate password length
- How to validate nested objects
- How to validate arrays
- How to return proper validation errors
- Difference between middleware-based and schema-based validation
- Difference between synchronous validation and async validation
